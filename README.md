# PassOP 🔐 — Simple Password Management App

**PassOP** is a web-application that lets users store and manage website credentials (usernames/passwords) locally using a browser. It’s built with React + localStorage for quick and easy password storage — ideal for personal use or learning full-stack fundamentals.

---

## 🚀 Features

- Store website name, username and password securely in browser localStorage.  
- Perform full CRUD (Create, Read, Update, Delete) operations for saved credentials.  
- Easy-to-use, intuitive UI built with React.  
- No backend — everything runs locally in the browser.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS  
- **Storage:** Browser `localStorage` — no external database needed  
- **Build tools (optional):** Vite / Create React App (depending on project setup)
